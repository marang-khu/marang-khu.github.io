基礎台語課程

學台語愛對發音開始。欲學台語發音，先愛熟似台語字母；koh愛沓沓仔增加台語詞彙。詞彙量若有夠，才會使自由講出家己心內ê想法，佮人溝通。句型、文法：台語文法佮華語無仝！！

學台語愛學啥物？

發音

學台語愛對發音開始。先熟似母音、子音佮拼寫規則，才有法度看羅馬字穩定讀出台語。

A E I O OO Uann enn inn onnp ph / t th / k kh

聲調

台語音節有七个基本聲調：五个舒聲調、兩个入聲調。字佮字鬥做伙，koh有本調、變調佮連紲變調。

詞彙佮生活

詞彙愛沓沓仔增加。詞彙量若有夠，才會使自由講出家己心內ê想法，佮人溝通。對食物、厝內、身軀到看病，lóng是日常生活會用著ê語言。

句型、文法

台語文法佮華語無仝！！問句、時態、代名詞、比較句佮語序，lóng愛直接用台語ê句型來練。

正音

會曉講台語，無代表逐个音攏已經分會清楚。聲母、鼻化、入聲韻尾佮第三聲、第七聲，是正音練習內底真重要ê所在。

進階聲調

一般變調以外，koh有 á 前變調、失調（輕聲）佮第九聲。欲講kah自然，這寡規則愛綴語句做伙練。

你可能會曉一寡日常生活台語，但是你nā beh做醫療，照護甚至上基本ê關心老大人等等，你敢會曉用台語正確表達？了解重要名詞án-tsuánn講，了解基本身體ê解說。

為啥物愛學羅馬字？

漢字佮發音無一定直接對應

漢字會曉看，無一定會曉唸；會曉唸，mā無一定知影彼ê字tī無仝詞內底ê聲音。羅馬字直接標出聲音，對學發音真有幫助。

羅馬字是聲音ê分析工具

一个音節會使拆做聲母、介音、韻腹、韻尾佮聲調。看會曉拆，聽音佮正音就khah有根據。

鼻化母音

鼻化用 nn 做記號，而且 nn 一定寫tī拼寫ê上尾。鼻化無等於加一个 n 韻尾；發音ê時，母音ê氣流有一部分ùi鼻腔出去。

pa / pann　pha / phann　ta / tann　tha / thann　ka / kann　kha / khann

pe / penn　phe / phenn　te / tenn　the / thenn　ke / kenn　khe / khenn

聲調符號囥佗位？

聲調符號一定寫tī母音頂頭。一般順序會使按呢記：

  • 有 a，聲調符號優先囥tī a：tâi、kái、kuài。
  • 無 a，有 e，囥tī e：uē。
  • i 佮 o 做伙，囥tī o：iô。
  • u 佮 i 做伙，囥tī後壁彼个母音：uî、iû。
  • oo 若有聲調，囥tī頭前彼个 o：ôo、tôo。
  • 若無母音，干焦有 m、ng，聲調符號直接寫tī頂頭：m̄、m̂、ńg、n̂g。

台語ê入聲，就是音節ê結尾出現塞音（韻尾塞音），用子音 p, t, k, h 收尾。第四聲ê音khah低，第八聲ê音khah懸；第八聲koh有聲調符號表示音懸。

一般舒聲變調

1 → 7　／　7 → 3　／　3 → 2　／　2 → 1　／　5 → 7（有ê腔口會變做 3）

入聲：第四聲變調會衝khah懸；第八聲變調會降kē。

台語ê「字」佮「字」鬥做伙，若超過一个音節，除了上尾一个音節，頭前ê音節通常愛變調。

連紲變調ê基本原則

完整ê一句話，上尾一个音節一定讀本調；話若猶未講了，上尾音節mā可能愛變調。

句中名詞ê結束音節維持本調。副詞、動詞、形容詞若m̄是佇話句上尾，通常愛變調。

「ê」tī句中會變調；「ê」頭前彼个音節維持本調。人稱代名詞一般情形lóng愛變調。

正音重點

正音毋是欲規定逐个人一定愛講仝一款腔口。這馬ê練習重點，是先予聲母、韻母、鼻化佮入聲韻尾分會清楚，koh用羅馬字幫助家己聽音佮校正發音。

聲母愛分清楚

組別正音重點練習

t / th / l / n舌尖ê接觸位置仝款，m̄-koh送氣、鼻音佮有聲方式無仝。ta / tha / la / na

進階聲調

一般本調佮變調掌握了後，koh有三組真重要ê現象：á 前變調、失調（輕聲）佮第九聲。這寡lóng愛放tī詞佮話句內底練，才會聽出差別。

á 前變調

「á」是台語真常見ê後綴，漢字常寫做「仔」。伊無法度單獨使用，一定佮別个詞鬥做伙。有幾个聲調tī á 頭前，變調方式佮一般規則無仝。

本調á 頭前例
1、2、4、5照一般變調kau-á　káu-á　toh-á　tsûn-á
3變做第一聲pòo-á　tshìn-á　kuà-á
7維持第七聲biō-á　kū-á　tē-á　kuī-á
8韻尾照舊，音值倚第七聲io̍h-á　tsha̍t-á　lo̍k-á　pu̍t-á

失調（輕聲）

失調一般講「輕聲變調」。羅馬字用兩个橫劃 -- 表示。失調ê音節會失去原來ê基本調，轉做固定ê輕聲，抑是綴頭前音節ê聲調。

Guá-ê tsheh bô--khì.　Guá beh koh lim--nn̄g-au.

實詞失調

動詞、形容詞佮一般名詞失調，常轉做固定ê低降短調。

kiann-sí / kiann--sí
āu-ji̍t / āu--ji̍t
phah-khui / phah--khui
bô-khì / bô--khì

虛詞失調

功能詞、語尾助詞、人稱代名詞等，會綴頭前音節ê聲調。頭前第一聲→第一聲；第五、七聲→第七聲；第二、三、入聲→第三聲。

tshenn--ê　tinn--ê　âng--ê　kóng--ê　tǹg--ê

三連音

台語三疊字形容詞會當表示真懸ê程度。若本調是 1、5、7、8，第一音節會出現第九聲，第二音節照一般變調，上尾音節維持本調。

醫用台語

醫學有足tsē專業用語。醫生／護士／照顧者有一个重要ê任務：Kā專業智識變做一般話語解說hōo人聽！ Tī台灣，干焦透過中文去做醫學智識ê解說是無夠--ê。對一般人，尤其是序大--ê，用台語做醫學上ê解說會予in koh khah好理解家己身體ê狀況。

醫學台語ài學啥物？

01 音節拆解

照順序看「聲母 → 介音 → 韻腹 → 韻尾」。∅ 就是這格無成分；四格攏毋免寫調號，聲調另外看提示。

guá 拆做 g / ∅ / ua / ∅，無介音；ua 是雙母音，規組囥佇韻腹。

uá 拆做 ∅ / ∅ / ua / ∅，ua 是雙母音，規組囥佇韻腹。tâi 拆做 t / ∅ / ai / ∅，ai 嘛是規組囥佇韻腹。

tiong 拆做 t / i / o / ng；tóng 是 t / ∅ / o / ng。韻尾 ng 是一个符號，愛做伙看；無調號嘛有聲調。

sing（生）是 s / ∅ / i / ng，無介音；i 是韻腹。

m̄（毋）是 ∅ / ∅ / m / ∅，m 佇遮擔當韻腹，無聲母、介音佮韻尾。

ōo（芋）是 ∅ / ∅ / oo / ∅；tóo（肚）是 t / ∅ / oo / ∅。兩个攏無介音佮韻尾，毋過 tóo 有聲母 t。

tshù（趣）是 tsh / ∅ / u / ∅，聲母 tsh 愛規組看。

03 聲母對照

「有聲、無聲」佮「送氣、無送氣」是兩款無仝的分別。有聲子音的聲帶有振動；無聲子音的聲帶無振動。送氣的對照，是聽氣有較強無。

有聲佮無聲：兩爿攏會使揿來聽
有聲無聲、無送氣

g–k、j–ts、b–p 是這關愛認的三組有聲佮無聲對照。一對一對聽，閣綴咧唸；毋通共有聲當做送氣。

送氣佮無送氣：這四組攏是無聲子音
無聲、無送氣無聲、送氣

手掌囥佇喙頭前，先聽 p–ph、t–th、k–kh、ts–tsh，閣綴咧唸，感覺送氣的差別。每一个聲母符號攏愛完整看；ng 嘛是一个完整的鼻音符號。
